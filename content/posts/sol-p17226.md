[题目链接](https://www.luogu.com.cn/problem/P17226)

设 `$R = \{x^2 \bmod p \mid x \in \mathbb{Z}_p^*\}$` 为模 `$p$` 的非零二次剩余集合，`$f(k,n)$` 为 `$k,n$` 对应的答案。显然有 `$f(k, n)=\sum_{r\in R}f(k-1, n-r)$`。直接 dp 的复杂度是 `$O(p^2k+Q)$`。

这个 dp 的第一维不太好优化，所以我们考虑压掉第二维。我们的约束是 `$\sum r_i \equiv n \pmod{p}$`，如果在等式两边同乘一个 `$r\in R$`，左边仍是 `$k$` 个 `$R$` 中元素的和（因为 `$R$` 对乘法封闭）。这建立了一个双射：

<div class="math-display">$$f(k, n)=f(k, nr)\qquad (r\in R)$$</div>

由 Legendre 符号的完全积性，`$n$` 和 `$nr$` 一定同为或同不为二次剩余（或同为 `$0$`）。因此我们可以按照 `$n=0,n\in R,n\not\in R$` 分为三类，三类中的 `$f(k,n)$` 都必定相等，记作 `$f_0(k), f_1(k), f_2(k)$`。

现在写出转移式（记 `$(-1/p)=\epsilon$`）：

<div class="math-display">$$
f_0(k)=\sum_{r\in R} f(k-1,-r)=\begin{cases}\frac{p-1}{2}f_1(k-1) &amp; \epsilon=1\\\frac{p-1}{2}f_2(k-1) &amp; \epsilon=-1\end{cases}
$$</div>

对于 `$f_1$` 和 `$f_2$`，我们可以通过之前的方式化归成 `$n=1$` 和 `$n=r^*$`（`$r^*$` 为一个任意的非二次剩余）的情况来推导：

<div class="math-display">$$
\begin{gathered}
f_1(k)=f(k,1)=\sum_{r\in R}f(k-1,1-r)=f_0(k-1)+f_1(k-1)\sum_{r\neq 1,r\in R}[1-r\in R]+f_2(k-1)\sum_{r\neq1,r\in R}[1-r\not\in R]\\
f_2(k)=f(k, r^*)=\sum_{r\in R}f(k-1,r^*-r)=f_1(k-1)\sum_{r\in R}[r^*-r\in R]+f_2(k-1)\sum_{r\in R}[r^*-r\not\in R]
\end{gathered}
$$</div>
显然每一项递推的系数都仅与 `$p$` 有关，那么可以预先算出系数，然后矩阵快速幂加速递推。复杂度 `$O(p+Q\log k)$`。

对 `$p\le 10^9$`，我们已不能通过枚举的方式算出系数。选手实战中可以通过打表找规律计算系数，不过我们题解中还是进行严格的推导。下仅推导 `$f_1(k),f_2(k)$` 的递推式中 `$f_1(k-1)$` 的系数；`$f_2(k-1)$` 的系数可以通过系数和为 `$|R|=(p-1)/2$` 轻易得出。

<div class="math-display">$$
\begin{aligned}
\sum_{r\neq 1,r\in R}[1-r\in R]
&amp;=\sum_{r=2}^{p-1}\frac{1+(r/p)}{2}\frac{1+((1-r)/p)}{2}\\
&amp;=\frac14\sum_{r=2}^{p-1}1+\left(\frac rp\right)+\left(\frac {1-r}p\right)+\left(\frac rp\right)\left(\frac {1-r}p\right)\\
&amp;=\frac14\left(p-2-1-1+\sum_{r=0}^{p-1}\left(\frac{r(1-r)}{p}\right)\right)
\end{aligned}
$$</div>

现在我们要算 `$\sum (r(1-r)/p)$`。方式有很多种，我们这里先证一个引理：

> Lemma: 
> <div class="math-display">$$\sum_{y=0}^{p-1}\left(\frac{y^2-a}p\right)=\begin{cases}p-1&amp;a=0\\-1&amp;a\neq 0\end{cases}$$</div>

证明：当 `$a=0$` 时，`$(y^2/p)=[y\neq 0]$`，显然得到结果为 `$p-1$`。
当 `$a\neq 0$` 时，考察方程 `$x^2=y^2-a$`。固定 `$y$` 时，易得 `$x$` 解数为 `$1+((y^2-a)/p)$`。故总解数为
<div class="math-display">$$
\sum_y1+\left(\frac{y^2-a}{p}\right)=p+\sum_{y}\left(\frac{y^2-a}{p}\right)
$$</div>
另一方面，考虑换元 `$u=y-x, v=y+x$`，则 `$uv=a$`。这建立了一个 `$(u,v)\to(x,y)$` 的双射。而 `$uv=a$` 显然固定其一就确定另一个，共 `$p-1$` 个解。即得 `$(x,y)$` 也共 `$p-1$` 个解。联立得到：
<div class="math-display">$$
\sum_y\left(\frac{y^2-a}{p}\right)=-1
$$</div>

回到原式，我们换元 `$y=2r-1$`，显然 `$y$` 仍然遍历 `$0,\dots,p-1$`，故求和结果不变。化简得到：
<div class="math-display">$$
\sum_r\left(\frac{r(1-r)}p\right)=\sum_y\left(\frac{(1-y^2)/4}p\right)=\epsilon\sum_y\left(\frac{y^2-1}{p}\right)=-\epsilon
$$</div>

于是代回原式就算出 `$\sum [1-r\in R]=\frac 14(p-4-\epsilon)$`。然后算 `$\sum_{r\in R}[r^*-r\in R]$`，过程与上面类似：

<div class="math-display">$$
\begin{aligned}
\sum_{r\in R}[r^*-r\in R]
&amp;=\sum_{r=1}^{p-1}\frac{1+(r/p)}{2}\frac{1+((r^*-r)/p)}2\\
&amp;=\frac14\sum_{r=1}^{p-1}1+\left(\frac rp\right)+\left(\frac {r^*-r}p\right)+\left(\frac rp\right)\left(\frac {r^*-r}p\right)\\
&amp;=\frac14\left(p-1+0+1+\sum_{r=0}^{p-1}\left(\frac{r(r^*-r)}p\right)\right)\\
&amp;=\frac14\left(p+\sum_{y=0}^{p-1}\left(\frac{({r^{*}}^2-y^2)/4}{p}\right)\right)\\
&amp;=\frac14\left(p+\epsilon\sum_{y=0}^{p-1}\left(\frac{y^2-{r^{*}}^2}{p}\right)\right)\\
&amp;=\frac{p-\epsilon}{4}
\end{aligned}
$$</div>

现在递推的系数可以 `$O(1)$` 算出。写成矩阵的形式就有：

<div class="math-display">$$
\begin{pmatrix}
f_0(k+1)\\ f_1(k+1) \\ f_2(k+1)
\end{pmatrix}=
\begin{pmatrix}
0 &amp; \frac{p-1}2[\epsilon=1] &amp; \frac{p-1}2[\epsilon=-1]\\
1 &amp; \frac{p-4-\epsilon}4 &amp; \frac{p-2+\epsilon}4\\
0 &amp; \frac{p-\epsilon}4 &amp; \frac{p-2+\epsilon}4
\end{pmatrix}
\begin{pmatrix}
f_0(k)\\ f_1(k)\\ f_2(k)
\end{pmatrix}
$$</div>

直接矩阵快速幂递推，复杂度为 `$O(Q(\log k+\log p))$`。每问重新算常数比较大，可以考虑用类似光速幂的方式预处理，能大幅减小常数（数据没有卡这个）。

本题同样可以借助 Gauss 和等工具推导出闭式解，但其前置知识过多，且复杂度没有额外提升，故在此不作更多介绍。

```cpp
#include <cstdio>
#include <cstring>

const int mod = 998244353;
using ll = long long;

struct Mat { int a[3][3]; Mat() { memset(a, 0, sizeof(a)); } };

Mat mul(Mat a, Mat b) {
    Mat res;
    for(int i = 0; i < 3; i ++)
        for(int j = 0; j < 3; j ++)
            for(int k = 0; k < 3; k ++)
                res.a[i][j] = (res.a[i][j] + 1LL * a.a[i][k] * b.a[k][j]) % mod;
    return res;
}

Mat fpow(Mat m, ll e) {
    Mat res; res.a[0][0] = res.a[1][1] = res.a[2][2] = 1;
    for(; e; e >>= 1, m = mul(m ,m)) if(e & 1) res = mul(res, m);
    return res;
}

int leg(int a, int p) { // (a/p)
    int e = (p - 1) / 2, chk = 1;
    for(; e; e >>= 1, a = 1LL * a * a % p) if(e & 1) chk = 1LL * chk * a % p;
    return (chk == 1);
}

int main() {
    int Q, p, ans = 0; scanf("%d%d", &Q, &p);

    int eps = 2 * (p % 4 == 1) - 1; Mat M; // eps = (-1/p)
    M.a[0][0] = 0, M.a[0][2 - (eps == 1)] = (p - 1) / 2;
    M.a[1][0] = 1, M.a[1][1] = (p - 4 - eps) / 4, M.a[1][2] = (p - 2 + eps) / 4;
    M.a[2][0] = 0, M.a[2][1] = (p - eps) / 4, M.a[2][2] = (p - 2 + eps) / 4;

    for(; Q; Q --) {
        ll k; int n; scanf("%lld%d", &k, &n);
        Mat Mk = fpow(M, k);

        if(!n) ans ^= Mk.a[0][0];
        else ans ^= Mk.a[2 - leg(n, p)][0];
    }

    printf("%d\n", ans);

    return 0;
}
```
