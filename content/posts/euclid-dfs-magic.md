设 $E&#40;u&#44;v&#41;$ 为对 $u&#44;v$（$u&#62;v$）进行辗转相除求 $&#92;gcd$ 的步数。我们希望研究使得 $E&#40;u&#44;v&#41;$ 较大的 $u&#44;v$。

众所周知辗转相除在对相邻 Fibonacci 数运行时最劣，因此若设 $f&#40;n&#41;&#61;&#92;max&#95;&#123;1&#92;le a&#60; n&#125; E&#40;n&#44;a&#41;$，$L&#40;N&#41;&#61;&#92;max&#95;&#123;1&#92;le n&#92;le N&#125;f&#40;n&#41;$，易知对 $L$ 有 $L&#40;N&#41;&#61;&#92;max k&#92; s&#46;t&#46;&#92;&#44;F&#95;&#123;k&#43;2&#125;&#92;le N$。

上面的结论是平凡的。我们尝试考察一点有意思的东西，即使得 $E&#40;u&#44;v&#41;$ **接近最大值**的 $u&#44;v$。具体而言，考察以下几种集合的大小：
$$
&#92;begin&#123;aligned&#125;
A&#95;j&#40;N&#41;&#38;&#61;&#92;&#123;n&#92;le N&#58;f&#40;n&#41;&#61;L&#40;N&#41;&#45;j&#92;&#125;&#92;&#92;
B&#95;j&#40;N&#41;&#38;&#61;&#92;&#123;&#40;a&#44;n&#41;&#58;1&#92;le a&#60;n&#92;le N&#44;&#92;&#44; E&#40;n&#44;a&#41;&#61;f&#40;n&#41;&#61;L&#40;N&#41;&#45;j&#92;&#125;&#92;&#92;
C&#95;j&#40;N&#41;&#38;&#61;&#92;&#123;&#40;u&#44;v&#41;&#58;1&#92;le v&#60;u&#92;le N&#44;&#92;&#44; E&#40;u&#44;v&#41;&#61;L&#40;N&#41;&#45;j&#92;&#125;
&#92;end&#123;aligned&#125;
$$
其中 $j$ 较小，设 $j&#92;le d$（一般当 $N$ 大时 $d$ 不会超过 $4$）。

## 连分数与爆搜

首先，辗转相除法的一堆迭代太难考察了，写成规范连分数的形式：$u&#47;v&#61;&#91;q&#95;1&#44;&#92;ldots&#44;q&#95;k&#93;$，其中 $q&#95;k&#92;ge 2$；那么有 $E&#40;u&#44;v&#41;&#61;k$。用连项式描述分子有 $u&#61;K&#40;q&#95;1&#44;&#92;ldots&#44;q&#95;k&#41;$。记 $K&#95;i&#61;K&#40;q&#95;1&#44;&#92;ldots&#44;q&#95;i&#41;$，则还有递推 $K&#95;i&#61;q&#95;iK&#95;&#123;i&#45;1&#125;&#43;K&#95;&#123;i&#45;2&#125;$（$K&#95;0&#61;1&#44;K&#95;&#123;&#45;1&#125;&#61;0$）。

连分数描述了所有互质对 $&#40;u&#44;v&#41;$。由于 $E&#40;u&#44;v&#41;&#61;E&#40;tu&#44;tv&#41;$，可以设 $&#92;lambda&#40;n&#41;&#61;&#92;max&#95;&#123;1&#92;le a&#60;n&#44;&#92;&#44; &#92;gcd&#40;a&#44;n&#41;&#61;1&#125;E&#40;n&#44;a&#41;$，那么有 $f&#40;n&#41;&#61;&#92;max&#95;&#123;u&#92;mid n&#125;&#92;lambda&#40;u&#41;$。从互质对出发，计算所有整数对的贡献是容易的；因此以下我们只考虑互质对。

由连分数视角，得到最坏情况是 Fibonacci 是容易的：显然 $u$ 关于任一个 $q&#95;i$ 都是递增的，$q&#95;i$ 全部取最小值得到 $u&#95;&#123;&#92;min&#125;&#61;K&#40;1&#44;&#92;ldots&#44;1&#44;2&#41;&#61;F&#95;&#123;k&#43;2&#125;$。这也给我们一些启示：固定前一部分系数 $q&#95;1&#44;&#92;ldots&#44;q&#95;i$（由递推关系我们只需要固定最后两个连项式，$A&#61;K&#95;i$ 和 $B&#61;K&#95;&#123;i&#45;1&#125;$），那么能够得到的最小分子就是连分数系数全取 $1$（末项取 $2$）。设还需要 $r&#61;k&#45;i$ 项，那么归纳递推得到 $u&#95;&#123;&#92;min&#125;&#61;K&#40;q&#95;1&#44;&#92;ldots&#44;q&#95;i&#44;1&#44;&#92;ldots&#44;1&#44;2&#41;&#61;F&#95;&#123;r&#43;2&#125;A&#43;F&#95;&#123;r&#43;1&#125;B$。

这个东西看起来很像一个剪枝，我们由此出发设计一个爆搜算法：爆搜中维护最后两个连项式，并枚举下一个连分数系数进行转移；如果步数等于 $L&#40;N&#41;&#45;j$，给相应的集合计算贡献；如果 $F&#95;&#123;r&#43;2&#125;A&#43;F&#95;&#123;r&#43;1&#125;B&#62;N$，就必定无法产生贡献，直接剪枝。其实这个爆搜约等于反向做辗转相除（区别是辗转相除是连分数系数从后往前递推），只是加上了一个剪枝。下面是一段伪代码（求 $&#124;C&#95;j&#124;$）：

```cpp
void dfs(int A, int B, int r) {
    if (r == 0) {
        ans += N / A;
        return;
    }
    for (int q = (r == 1 ? 2 : 1); ; ++q) {
        int C = q * A + B;
        int lower = (r == 1 ? C : F[r + 1] * C + F[r] * A);
        if (lower > N) break;
        dfs(C, A, r - 1);
    }
}
```

看上去这个爆搜比 $O&#40;N&#94;2&#41;$ 的暴力快不了多少，但是实际上跑得很快，$N&#61;10&#94;7&#44;j&#92;le 4$ 能在几秒钟内出来。以下我们来分析为什么它跑得这么快。

## $j&#61;0$

首先考察 $j&#61;0$ 时的情况。感性理解：这种时候，连分数系数一定不会偏离 Fibonacci 时的太多。因此设 $b&#61;&#40;1&#44;&#92;ldots&#44;1&#44;2&#41;$。并令偏移量 $e&#95;i&#61;q&#95;i&#45;b&#95;i$。下面给出一个基于偏移量的估算。

> **引理（连项式偏移估算）。** 令 $b&#61;&#40;1&#44;&#92;ldots&#44;1&#44;2&#41;$，设 $q&#95;i&#61;b&#95;i&#43;e&#95;i$，其中 $e&#95;i&#92;ge 0$，则
> $$
> K&#40;q&#95;1&#44;&#92;ldots&#44;q&#95;k&#41;&#92;ge F&#95;&#123;k&#43;2&#125;&#92;prod&#95;&#123;i&#61;1&#125;&#94;k&#40;1&#43;e&#95;i&#47;3&#41;
> $$

**证明。** 记 $K&#95;&#123;l&#44;r&#125;&#61;K&#40;q&#95;l&#44;&#92;ldots&#44;q&#95;r&#41;$，设 $A&#61;K&#95;&#123;1&#44;i&#45;1&#125;$，$B&#61;K&#95;&#123;i&#43;1&#44;k&#125;$，$A&#94;&#45;&#61;K&#95;&#123;1&#44;i&#45;2&#125;$，$B&#94;&#45;&#61;K&#95;&#123;i&#43;2&#44;k&#125;$。连项式的拼接性质给出：
$$
K&#40;q&#95;1&#44;&#92;ldots&#44;q&#95;k&#41;&#61;Aq&#95;iB&#43;A&#94;&#45;B&#43;AB&#94;&#45;
$$
设 $x&#61;A&#94;&#45;&#47;A$，$y&#61;B&#94;&#45;&#47;B$，则由连项式递推有 $0&#92;le x&#44;y&#92;le 1$。故有 $K&#40;q&#95;1&#44;&#92;ldots&#44;q&#95;k&#41;&#61;AB&#40;q&#95;i&#43;x&#43;y&#41;$。

现在从 $q&#61;b$ 出发，依次修改每一位 $q&#95;i&#92;gets b&#95;i&#43;e&#95;i$。每次修改前后比值为
$$
&#92;frac&#123;b&#95;i&#43;e&#95;i&#43;x&#43;y&#125;&#123;b&#95;i&#43;x&#43;y&#125;&#61;1&#43;&#92;frac&#123;e&#95;i&#125;&#123;b&#95;i&#43;x&#43;y&#125;
$$
显然有 $b&#95;i&#43;x&#43;y&#92;le 3$，因此比值不小于 $1&#43;e&#95;i&#47;3$。上述比值的下界在每一步都成立，因此得证。

根据以上估计，$j&#61;0$ 时的情况呼之欲出。

> **引理（$j&#61;0$ 情况）。** $f&#40;n&#41;&#61;L&#40;N&#41;$（$n&#92;le N$）仅有两种情况：$n$ 为斐波那契数，或 $n&#61;K&#40;q&#95;1&#44;&#92;ldots&#44;q&#95;k&#41;$ 对应的偏离量 $e$ 中仅有一项为 $1$，其余全为 $0$。注意后一种情况仅为必要条件。

**证明。** 令 $L&#61;L&#40;N&#41;$，那么 $f&#40;n&#41;&#61;L&#40;N&#41;$ 必须有 $n&#92;le N&#60;F&#95;&#123;L&#43;3&#125;$，进而有 $n&#47;F&#95;&#123;L&#43;2&#125;&#60;F&#95;&#123;L&#43;3&#125;&#47;F&#95;&#123;L&#43;2&#125;&#92;le 5&#47;3$。在此基础上，只要规范连分数长度 $k&#61;L$ 即可。

由单调性只需要考虑两种例外：$e$ 中一项为 $2$，其余为 $0$；或 $e$ 中两项为 $1$。由之前的引理得，两者的 $n&#47;F&#95;&#123;L&#43;2&#125;$ 分别至少为 $5&#47;3$ 和 $16&#47;9$，必然不满足 $n&#47;F&#95;&#123;L&#43;2&#125;&#60;5&#47;3$。故得证。

当 $e&#95;i&#61;1$，其余项为 $0$ 时，有 $K&#40;q&#95;1&#44;&#92;ldots&#44;q&#95;k&#41;&#61;F&#95;&#123;L&#43;2&#125;&#43;F&#95;iF&#95;&#123;L&#43;2&#45;i&#125;$。对该类情况可以直接枚举 $i$ 进行计数，判断分子是否不超过 $N$ 即可，复杂度约为 $O&#40;L&#41;&#61;O&#40;&#92;log N&#41;$。求 $&#124;A&#95;0&#124;$ 需要把所有得到的 $n$ 排序之后去重，复杂度为 $O&#40;L&#92;log L&#41;$。

## 一般情况

下面考虑偏一般的情况。

> **引理（一般步数下的数量上界）。** 设 $W&#95;k&#40;N&#41;$ 为分子不超过 $N$，且连分数长度为 $k$ 的 $u&#47;v$ 个数。再令 $t&#61;&#92;lfloor &#92;log&#95;&#123;4&#47;3&#125;&#40;N&#47;F&#95;&#123;k&#43;2&#125;&#41;&#92;rfloor$，则有：
> $$
> W&#95;k&#40;N&#41;&#92;le 2&#94;t&#92;binom&#123;k&#43;t&#125;&#123;k&#125;
> $$

**证明。** 令 $R&#61;N&#47;F&#95;&#123;k&#43;2&#125;$，由之前的引理，我们需要满足 $&#92;prod&#40;1&#43;e&#95;i&#47;3&#41;&#92;le R$。

进行一些放缩魔术！令 $y&#95;i&#61;&#92;lfloor&#92;log&#95;2&#40;e&#95;i&#43;1&#41;&#92;rfloor$，则固定 $y&#95;i$ 时 $e&#95;i$ 共有 $2&#94;&#123;y&#95;i&#125;$ 种取值。放缩一下有：
$$
1&#43;&#92;frac&#123;e&#95;i&#125;3&#92;ge&#92;frac&#123;2&#94;&#123;y&#95;i&#125;&#43;2&#125;3&#92;ge &#92;left&#40;&#92;frac43&#92;right&#41;&#94;&#123;y&#95;i&#125;
$$
那么必定有 $&#40;4&#47;3&#41;&#94;&#123;&#92;sum y&#95;i&#125;&#92;le R$，即 $&#92;sum y&#95;i&#92;le t$。枚举 $s&#61;&#92;sum y&#95;i&#92;le t$，那么固定 $s$ 时的 $e$ 序列数量有上界为
$$
&#92;sum&#95;&#123;&#92;sum y&#95;i&#61;s&#125;&#92;prod&#95;&#123;i&#61;1&#125;&#94;k 2&#94;&#123;y&#95;i&#125;&#61;2&#94;s&#92;binom&#123;s&#43;k&#45;1&#125;&#123;s&#125;
$$
直接求和得到 $W&#95;k&#40;N&#41;$ 的一个上界，再将 $2&#94;s$ 全部放缩成 $2&#94;t$，得到
$$
W&#95;k&#40;N&#41;&#92;le&#92;sum&#95;&#123;s&#61;0&#125;&#94;t2&#94;s&#92;binom&#123;s&#43;k&#45;1&#125;s&#92;le 2&#94;t&#92;binom&#123;k&#43;t&#125;k
$$
令 $L&#61;L&#40;N&#41;$。现在对 $L&#45;d&#92;le k&#92;le L$ 的 $k$ 求和，就得到我们希望考察的几个集合大小的一个估计：
$$
&#92;mathcal W&#40;N&#44;d&#41;&#61;&#92;sum&#95;&#123;k&#61;L&#45;d&#125;&#94;&#123;L&#125;W&#95;k&#40;N&#41;
$$
对每个 $W&#95;k&#40;N&#41;$ 的 $t$ 做一个估计：$N&#47;F&#95;&#123;k&#43;2&#125;&#60;F&#95;&#123;L&#43;3&#125;&#47;F&#95;&#123;k&#43;2&#125;&#60;2&#94;&#123;L&#45;k&#43;1&#125;&#92;le 2&#94;&#123;d&#43;1&#125;$，故 $t&#60;&#40;d&#43;1&#41;&#92;log&#95;&#123;4&#47;3&#125;2&#60;3&#40;d&#43;1&#41;$。对所有 $k$ 我们统一取 $t$ 的上界 $T&#61;3&#40;d&#43;1&#41;$，则有
$$
&#92;mathcal W&#40;N&#44;d&#41;&#92;le &#40;d&#43;1&#41;2&#94;T&#92;binom&#123;L&#43;T&#125;&#123;T&#125;&#92;le &#40;d&#43;1&#41;2&#94;T&#92;left&#40;&#92;frac&#123;e&#40;L&#43;T&#41;&#125;&#123;T&#125;&#92;right&#41;&#94;T
$$
取对数有
$$
&#92;log &#92;mathcal W&#40;N&#44;d&#41;&#92;le &#92;log&#40;d&#43;1&#41;&#43;T&#92;log 2&#43;T&#92;log&#92;frac&#123;e&#40;L&#43;T&#41;&#125;T
$$
由 $T&#61;O&#40;d&#41;$，$d&#92;le L&#45;1$，右边大概是 $O&#40;d&#92;log&#40;1&#43;L&#47;d&#41;&#41;$，故有
$$
&#92;mathcal W&#40;N&#44;d&#41;&#61;&#92;exp&#92;left&#40;O&#92;left&#40;d&#92;log&#92;left&#40;1&#43;&#92;frac Ld&#92;right&#41;&#92;right&#41;&#92;right&#41;
$$
之前的 dfs 复杂度也就可以得到解释：搜索树叶子节点有 $&#92;mathcal W&#40;N&#44;d&#41;$ 个，搜索深度至多 $L$，那么复杂度就是 $O&#40;L&#92;cdot &#92;mathcal W&#40;N&#44;d&#41;&#41;$ 的。求 $&#124;A&#95;j&#124;$，$&#124;B&#95;j&#124;$ 时需要把所有得到的初始对按照分子分类统计，任意初始对一共有 $Q&#92;le &#92;lfloor N&#47;F&#95;&#123;L&#45;d&#43;2&#125;&#92;rfloor &#92;mathcal W&#40;N&#44;d&#41;&#92;le 2&#94;d&#92;mathcal W&#40;N&#44;d&#41;$ 个，故复杂度为 $O&#40;L&#92;mathcal W&#40;N&#44;d&#41;&#43;Q&#92;log Q&#41;$。

当然我们同样可以估计 $&#92;mathcal W&#40;N&#44;d&#41;$ 的下界。考虑构造一批满足条件的连分数系数列。从长度 $k&#61;L&#45;d$ 的最小序列 $&#40;1&#44;&#92;ldots&#44;1&#44;2&#41;$ 出发，考虑任意选 $t&#92;le d$ 个位置，将其中的 $1$ 改成 $2$。一个观察是一个 $2$ 对最终分子的贡献不如两个 $1$（由连项式递推容易验证），因此这样构造出的分子一定不超过 $F&#95;&#123;k&#43;t&#43;2&#125;&#92;le F&#95;&#123;L&#43;2&#125;&#92;le N$，故是合法的。枚举位置集合得到一个下界：
$$
&#92;mathcal W&#40;N&#44;d&#41;&#92;ge &#92;sum&#95;&#123;t&#61;0&#125;&#94;&#123;&#92;min&#40;d&#44;L&#45;d&#45;1&#41;&#125;&#92;binom&#123;L&#45;d&#45;1&#125;&#123;t&#125;
$$
按 $d$ 分情况缩放。当 $d&#92;le L&#47;4$ 时，只取 $t&#61;d$ 的部分有
$$
&#92;mathcal W&#40;N&#44;d&#41;&#92;ge &#92;binom&#123;L&#45;d&#45;1&#125;&#123;d&#125;&#92;ge&#92;left&#40;&#92;frac L&#123;2d&#125;&#92;right&#41;&#94;d&#61;&#92;exp&#92;left&#40;&#92;Omega&#92;left&#40;d&#92;log&#92;left&#40;1&#43;&#92;frac Ld&#92;right&#41;&#92;right&#41;&#92;right&#41;
$$
当 $d&#62;L&#47;4$ 时，只取 $t&#61;&#92;lfloor L&#47;4&#92;rfloor$，并取连分数长度 $k&#61;L&#45;t$。此时有
$$
&#92;mathcal W&#40;N&#44;d&#41;&#92;ge &#92;binom&#123;L&#45;t&#45;1&#125;&#123;t&#125;&#92;ge 2&#94;t&#61;&#92;exp&#40;&#92;Omega&#40;L&#41;&#41;
$$
而该情况下又有 $d&#92;log&#40;1&#43;L&#47;d&#41;&#61;&#92;Theta&#40;L&#41;$。综上可以得到 $&#92;mathcal W&#40;N&#44;d&#41;$ 的比较精确的估计
$$
&#92;boxed&#123;&#92;mathcal W&#40;N&#44;d&#41;&#61;&#92;exp&#92;left&#40;&#92;Theta&#92;left&#40;d&#92;log&#92;left&#40;1&#43;&#92;frac Ld&#92;right&#41;&#92;right&#41;&#92;right&#41;&#125;
$$

### 稀疏性

以上 $&#92;mathcal W&#40;N&#44;d&#41;$ 估计可以自然得到一个关于辗转相除步数接近上限的密度的推论。

> **推论（步数近上限密度）。** 设 $&#92;Delta&#40;n&#41;&#61;L&#40;n&#41;&#45;f&#40;n&#41;$。当 $N$ 足够大时，除了一个大小为 $o&#40;N&#41;$ 的集合，对剩下的 $n&#92;le N$ 都有 $&#92;Delta&#40;n&#41;&#61;&#92;Omega&#40;&#92;log n&#41;$。

**证明。** 令 $L&#61;L&#40;N&#41;$。设 $H&#95;d&#40;N&#41;&#61;&#124;&#92;&#123;n&#92;le N&#58;&#92;Delta&#40;n&#41;&#92;le d&#92;&#125;&#124;$。设 $X&#95;k&#61;&#92;min&#40;N&#44;F&#95;&#123;k&#43;d&#43;3&#125;&#45;1&#41;$，并考察每个长为 $k$ 的连分数可能做的贡献，有：
$$
&#92;&#123;n&#92;le N&#58;&#92;Delta&#40;n&#41;&#92;le d&#92;&#125;&#61;&#92;bigcup&#95;&#123;k&#61;1&#125;&#94;&#123;L&#125;&#92;bigcup&#95;&#123;&#92;substack&#123;&#124;q&#124;&#61;k&#92;&#92;K&#40;q&#41;&#92;le X&#95;k&#125;&#125;&#92;left&#92;&#123;tK&#40;q&#41;&#58;1&#92;le t&#92;le &#92;left&#92;lfloor &#92;frac&#123;X&#95;k&#125;&#123;K&#40;q&#41;&#125;&#92;right&#92;rfloor &#92;right&#92;&#125;
$$
这里的上界估计可以复用之前 $W&#95;k&#40;N&#41;$ 的结果，并集直接用求和估计上界，得到：
$$
H&#95;d&#40;N&#41;&#92;le &#92;sum&#95;&#123;k&#61;1&#125;&#94;L&#92;sum&#95;&#123;&#92;substack&#123;&#124;q&#124;&#61;k&#92;&#92;K&#40;q&#41;&#92;le X&#95;k&#125;&#125;&#92;left&#92;lfloor &#92;frac&#123;X&#95;k&#125;&#123;K&#40;q&#41;&#125;&#92;right&#92;rfloor&#92;le &#92;sum&#95;&#123;k&#61;1&#125;&#94;L&#92;left&#92;lfloor&#92;frac&#123;F&#95;&#123;k&#43;d&#43;3&#125;&#125;&#123;F&#95;&#123;k&#43;2&#125;&#125;&#92;right&#92;rfloor W&#95;k&#40;X&#95;k&#41;&#92;le 2&#94;&#123;d&#43;1&#125;&#92;sum&#95;&#123;k&#61;1&#125;&#94;LW&#95;k&#40;X&#95;k&#41;
$$
接下来的估计过程与 $&#92;mathcal W&#40;N&#44;d&#41;$ 几乎相同。带入之前 $W&#95;k&#40;N &#41;$ 的估计，并统一取 $T&#61;3&#40;d&#43;1&#41;$，得到
$$
H&#95;d&#40;N&#41;&#92;le L2&#94;&#123;d&#43;T&#43;1&#125;&#92;binom&#123;L&#43;T&#125;&#123;T&#125;
$$
这就给出 
$$
H&#95;d&#40;N&#41;&#61;&#92;exp&#92;left&#40;O&#92;left&#40;&#40;d&#43;1&#41;&#92;log&#92;left&#40;1&#43;&#92;frac&#123;L&#125;&#123;d&#43;1&#125;&#92;right&#41;&#92;right&#41;&#92;right&#41;
$$

现在考虑固定 $d&#61;&#92;varepsilon L$，其中 $&#92;varepsilon&#92;to 0$，那么得到 $&#92;log H&#95;d&#40;N&#41;&#61;O&#40;&#92;varepsilon&#92;log&#40;1&#43;1&#47;&#92;varepsilon&#41;L&#41;$。由于 $&#92;log N&#92;sim L&#92;log&#92;phi$，而 $&#92;varepsilon&#92;log&#40;1&#43;1&#47;&#92;varepsilon&#41;&#92;to 0$，可以得到 $H&#95;d&#40;N&#41;&#61;O&#40;N&#94;&#123;1&#45;&#92;eta&#125;&#41;&#61;o&#40;N&#41;$。也就是说，当 $N$ 足够大时，除了 $H&#95;d&#40;N&#41;$ 个 $n$，其余绝大多数 $n$ 都满足 $&#92;Delta&#40;n&#41;&#92;ge &#92;varepsilon L&#61;&#92;Omega&#40;&#92;log N&#41;$。

以上推论也说明，对随机输入运行欧几里得算法，步数很难达到理论上界。
