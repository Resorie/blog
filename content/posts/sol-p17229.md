## Splitting Trick

考察 `$x/y$` 的连分数表示 `$x/y=[a_0;a_1,\dots,a_k]$`，其为欧几里得算法中的商序列。一般而言其有两种解释：

### Continuants

数列 `$b_0,\dots,b_k$` 的 continuant `$K(b_0,\dots,b_k)$` 是如下递归定义的多项式：

- `$K() = 1$`（空序列）；
- `$K(b_0) = b_0$`；
- `$k\ge1$` 时：`$K(b_0,\dots,b_k) = b_kK(b_0, \dots, b_{k-1}) + K(b_0, \dots, b_{k-2})$`。

Continuants 相关的性质大多由数学归纳法易证。下列出几个较为重要的性质：

**1. 回文性质** `$K(b_0, \ldots, b_k) = K(b_k, \ldots, b_0)$`。因此等价地有左递推：
<div class="math-display">$$
K(b_0, \ldots, b_k) = b_0 \cdot K(b_1, \ldots, b_k) + K(b_2, \ldots, b_k)
$$</div>

下为书写简便，对给定的连分数商序列 `$\{a_n\}$`，记 `$Q(l, r) = K(a_l, \ldots, a_r)$`（`$l \le r$`），并约定 `$Q(l, l-1) = 1,Q(l,l-2)=0$`。

**2. 与连分数的关系** 对 `$x/y = [a_0, a_1, \dots, a_k]$`（`$\gcd(x, y) = 1$`），其收敛子 `$p^*_i/q^*_i=[a_0,\dots,a_i]$` 满足
<div class="math-display">$$
p^*_i = Q(0, i), \quad q^*_i = Q(1, i)
$$</div>

特别地，`$x = Q(0, k)$`，`$y = Q(1, k)$`。

更泛化地说，从 `$l$` 到 `$r$` 的连分数序列段，由之前的回文性质，有正向和反向两种表示方法：

<div class="math-display">$$
\begin{gathered}
[a_l,a_{l+1},\dots,a_r]=\frac{Q(l,r)}{Q(l+1,r)} \\
[a_r,a_{r-1},\dots,a_l]=\frac{Q(l,r)}{Q(l,r-1)}
\end{gathered}
$$</div>

**3. Euler 恒等式** 对 `$l \le m < r$`：
<div class="math-display">$$
Q(l, r) = Q(l, m) \cdot Q(m+1, r) + Q(l, m-1) \cdot Q(m+2, r)
$$</div>

### Matrices

类似 Half-GCD 的视角，欧几里得算法可以看作一系列矩阵的连乘：
<div class="math-display">$$
\begin{pmatrix}x&amp;*\\y&amp;*\end{pmatrix}=M=\prod_{i=0}^kM(a_i)\quad\text{where }M(a)=\begin{pmatrix}a&amp;1\\1&amp;0\end{pmatrix}
$$</div>
由于矩阵乘法有结合律，可以从中间某个地方断开，考察连续一段的乘积：
<div class="math-display">$$
P(l,r)=\prod_{i=l}^rM(a_i)
$$</div>
可以验证
<div class="math-display">$$
P(l,r)=\begin{pmatrix}
Q(l,r) &amp; Q(l, r-1)\\
Q(l+1,r) &amp; Q(l+1,r-1)
\end{pmatrix}
$$</div>
如果考察 `$P(l,r)=P(l,m)P(m+1,r)$`，可以得到 Euler 恒等式。

### Split

考虑将 `$M$` 拆成若干个区间乘积 `$P(l_i,r_i)$` 之积，即 

<div class="math-display">$$
M=\prod_{i=1}^sP(l_i,r_i),\quad l_1=0,r_s=k,\quad l_i=r_{i-1}+1(2\le i\le s)
$$</div>

将右侧的乘积展开，就能得到关于 `$x,y$` 的一些等式。一般而言，如果大量的 `$P$` 是确定的，只留 `$1$`（平凡）或 `$2$` 个自由的 `$P$`，这个等式的形式会易于处理。下以 `$s=2$` 的情况为例，这也是本题的情况：
<div class="math-display">$$
\begin{pmatrix}x&amp;*\\y&amp;*\end{pmatrix}=\begin{pmatrix}
Q(0,t) &amp; Q(0,t-1)\\
Q(1,t) &amp; Q(1,t-1)
\end{pmatrix}
\begin{pmatrix}
Q(t+1,k) &amp; Q(t+1,k-1)\\
Q(t+2,k) &amp; Q(t+2,k-1)
\end{pmatrix}
$$</div>

考察右侧矩阵乘法中生成左侧矩阵 `$(1,1)$` 位置（即值 `$x$`）的式子：
<div class="math-display">$$
x=Q(0,t)\cdot Q(t+1,k)+Q(0,t-1)\cdot Q(t+2,k)
$$</div>

令
<div class="math-display">$$
X=Q(0,t),\quad Y=Q(0,t-1),\quad Z=Q(t+1,k),\quad W=Q(t+2,k)
$$</div>
则我们几乎建立了一个 `$(x,y,t)$` 到 `$(X,Y,Z,W)$` 的双射（边界情况需要修正）。对 `$(x,y,t)$` 的约束为
<div class="math-display">$$
1\le y&lt;x\le N,\quad 0\le t&lt;k
$$</div>
对 `$(X,Y,Z,W)$` 的约束为
<div class="math-display">$$
\gcd(X,Y)=\gcd(Z,W)=1,\quad X\ge Y\ge1,\,Z\ge W\ge1,\quad XZ+YW=x\le N
$$</div>
该换元的好处是去除了极难处理的 `$t$` 的约束，同时仍能表示原来的连分数序列，因为：

<div class="math-display">$$
\frac XY=[a_t;a_{t-1},\dots,a_0],\quad \frac ZW=[a_{t+1};a_{t+2},\dots, a_k]
$$</div>

因此，我们只需要把 `$X/Y$` 的连分数序列反向，然后和 `$Z/W$` 的连分数序列拼在一起，就得到 `$x/y$` 的连分数序列。

对 `$s>2$`，但仍只有两个自由的 `$P$` 的情况，我们实际上是枚举了连分数序列中的两个自由段，最后将它们其一反向，并与其他的非自由段拼接在一起，此处不作额外推导。

## Sol

本题解介绍一个较容易理解且常数较小的 `$O(N^{5/4}\log N)$` 算法。~~写 Sol 时的我尚不知道 std 会被 @ForgotMe 的赛时代码爆得渣都不剩，orz ForgotMe~~

约定 `$g(0)=h(0)=0$`。设连分数表示 `$a/b=[q_0, \dots, q_k]$`，那么 `$f(a,b)=\sum g(q_i)h(q_{i+1})$`。该求和的每一项都对应之前所述的一个 split。用取整符号可以提取出连分数的首项；再对所有互质对 `$a,b$` 求和，我们就大概得到这样的式子：

<div class="math-display">$$
S(N)\sim\sum_{\substack{XZ+YW\le N\\X\ge Y,\, Z\ge W\\ \gcd(X,Y)=\gcd(Z,W)=1}}g(\lfloor X/Y\rfloor)h(\lfloor Z/W\rfloor)
$$</div>

当然我们还要处理边界情况，下进行分析。

1. 对 `$Z=W$` 的情况，连分数末尾项必为 `$1$`，但欧几里得算法的最后一步商必不可能为 `$1$`，直接排除；
2. 对 `$Y\neq 1$`，`$X/Y$` 对应两个连分数（因为 `$[\dots, t]=[\dots, t-1, 1]$`，`$Y\neq 1$` 保证了 `$\dots$` 不为空），答案中贡献为 `$2g(\lfloor X/Y\rfloor)h(\lfloor Z/W\rfloor)$`；
3. 对 `$Y=1,\, X\ge 2$`，`$X/Y=[X]=[X-1; 1]$`，答案中贡献为 `$(g(X)+g(X-1))h(\lfloor Z/W\rfloor)$`；
4. 对 `$X=Y=1$`，答案中贡献为 `$g(1)h(\lfloor Z/W\rfloor)$`。

统计答案时，我们分为 `$X>Y,\, Z>W$` 的主体部分和剩下的修正项。具体地，定义修正系数：

<div class="math-display">$$
\rho(x)=\begin{cases}g(1)&amp;x=1\\g(x-1)-g(x)&amp;x\ge 2\end{cases}
$$</div>

那么 `$S(N)$` 可以拆成（主体求和记作 `$C_0$`，修正项记作 `$R_0$`）：

<div class="math-display">$$
S(N)=2\underbrace{\sum_{\substack{XZ+YW\le N\\X&gt;Y\ge 1,\, Z&gt;W\ge 1\\ \gcd(X,Y)=\gcd(Z,W)=1}}g(\lfloor X/Y\rfloor)h(\lfloor Z/W
\rfloor)}_{C_0(N)}+\underbrace{\sum_{\substack{XZ+W\le N\\X\ge 1,\, Z&gt;W\ge 1\\\gcd(Z,W)=1}}\rho(X)h(\lfloor Z/W\rfloor)}_{R_0(N)}
$$</div>

莫反之后即需要处理去掉互质条件的两项求和，即：

<div class="math-display">$$
\begin{aligned}
C_0(N)=\sum_{d\ge 1}(\mu*\mu)(d)C(\lfloor N/d\rfloor),&amp;\quad\text{where } C(M)=\sum_{\substack{XZ+YW\le M\\X&gt;Y\ge 1,\, Z&gt;W\ge 1}}g(\lfloor X/Y\rfloor)h(\lfloor Z/W\rfloor)\\
R_0(N)=\sum_{d\ge 1}\mu(d)R(\lfloor N/d\rfloor),&amp;\quad\text{where } R(M)=\sum_{\substack{XZ+W\le M\\X\ge 1,\, Z&gt;W\ge 1}}\rho(X)h(\lfloor Z/W\rfloor)
\end{aligned}
$$</div>

接下来讨论 `$C(M)$` 和 `$R(M)$`。

### `$\operatorname{pref}$`

对 `$p\in\{g, h\}$`，以下会常用到这样一类前缀和：

<div class="math-display">$$
\operatorname{pref}_p(A,d)=\sum_{x=1}^Ap(\lfloor x/d\rfloor)
$$</div>

令 `$q=\lfloor A/d\rfloor$`，那么 `$\lfloor x/d\rfloor$` 跨越了 `$q-1$` 个完整的“块”，以及一个 `$(A\bmod d)+1$` 大小的余项。因此得到：

<div class="math-display">$$
\operatorname{pref}_p(A,d)=d\sum_{t=1}^{q-1}p(t)+(A-dq+1)p(\lfloor A/d\rfloor)
$$</div>

另有 `$\operatorname{pref}_p(x,x)=p(1),\, \operatorname{pref}_p(A,d)=0(A<d)$`。

实现中，我们预处理

<div class="math-display">$$
B_p(q)=\sum_{t=1}^{q-1}p(t)-qp(q),\quad q\ge 1
$$</div>

那么可以 `$\operatorname{pref}_p(A,d)=(A+1)p(q)+dB_p(q)$`，`$O(1)$` 计算。

### `$R$`

枚举 `$X,W$`，此时 `$Z\le\lfloor(M-W)/X\rfloor$`。故固定 `$X,W$` 时的贡献为

<div class="math-display">$$
\operatorname{pref}_h\left(\left\lfloor\frac{M-W}{X}\right\rfloor,W\right)-\operatorname{pref}_h(W,W)
$$</div>

由于 `$Z\ge 2$`，对 `$X$` 有 `$2X+1\le M$`。由于 `$Z\ge W+1$`，对 `$W$` 有 `$X(W+1)+W\le M$`，即 `$W\le\lfloor(M-X)/(X+1)\rfloor$`。故对 `$R(M)$`：

<div class="math-display">$$
R(M)=\sum_{\substack{X\ge 1\\2X+1\le M}}\rho(X)\sum_{W=1}^{\left\lfloor\frac{M-X}{X+1}\right\rfloor}\left(\operatorname{pref}_h\left(\left\lfloor\frac{M-W}{X}\right\rfloor,W\right)-\operatorname{pref}_h(W,W)\right)
$$</div>

直接枚举 `$(X,W)$`，单次计算复杂度为 `$O(\sum_{X<M/2}M/X)=O(M\log M)$`。

### `$C$`

注意到求和限制中 `$(X, Y)$` 和 `$(Z, W)$` 的地位是完全对称的，考虑限定其字典序顺序。分为两种情况：`$(X,Y)=(Z,W)$` 和 `$(X,Y)<_\text{lex}(Z,W)$`。于是有

<div class="math-display">$$
\begin{aligned}
C(M)
&amp;=\sum_{(X,Y)=(Z,W)}g(\lfloor X/Y\rfloor)h(\lfloor Z/W\rfloor)\\
&amp;+\sum_{(X,Y)&lt;_\text{lex}(Z,W)}\left(g(\lfloor X/Y\rfloor)h(\lfloor Z/W\rfloor)+h(\lfloor X/Y\rfloor)g(\lfloor Z/W\rfloor)\right)
\end{aligned}
$$</div>

由于 `$X\le Z$`，有 `$X\le \sqrt{XZ}\le \sqrt M$`，这大幅减小了求和范围。

`$(X,Y)=(Z,W)$` 的情况是简单的：直接枚举 `$(X,Y)$` 即可，复杂度 `$O(M)$`。这一步可以在后一种情况的循环中顺手加上。

对 `$(X,Y)<_\text{lex}(Z,W)$` 的情况，考虑枚举 `$(X,Y)$`。固定 `$(X,Y,W)$` 后，有 `$Z\le\lfloor(M-YW)/X\rfloor$`。设 `$Z$` 的上限 `$A_W=\lfloor(M-YW)/X\rfloor$`，则我们要求的是：

<div class="math-display">$$
\sum_{\substack{W\ge 1\\ A_W\ge\max(X,W)}}\sum_{\max(X,W)\le Z\le A_W}p(\lfloor Z/W\rfloor)
$$</div>

注意限定字典序后 `$p$` 也可能取 `$g$`。这里的边界不等式需要稍精细的处理，我们更细地分成三种大小关系来讨论：

1. `$Z>X\ge W$`

一定有 `$Z>W$`，故只需保证 `$Z>X$` 存在，即有 `$X(X+1)+YW\le M$`。令

<div class="math-display">$$
W_0=\min\left(X,\left\lfloor\frac{M-X(X+1)}{Y}\right\rfloor\right)
$$</div>

那么这一段的贡献为

<div class="math-display">$$
\sum_{W=1}^{W_0}\left(\operatorname{pref}_p(A_W,W)-\operatorname{pref}_p(X,W)\right)
$$</div>

2. `$Z>X, W>X$`

此时 `$Z>W$` 更强，即需保证 `$X(W+1)+YW\le M$`。令

<div class="math-display">$$
W_1=\left\lfloor\frac{M-X}{X+Y}\right\rfloor
$$</div>

那么这一段的贡献为

<div class="math-display">$$
\sum_{W=X+1}^{W_1}\left(\operatorname{pref}_p(A_W,W)-\operatorname{pref}_p(W,W)\right)
$$</div>

3. `$X=Z$`

`$W$` 的限制为 `$Y<W<X$`，且 `$X^2+YW\le M$`。令

<div class="math-display">$$
W_2=\min\left(X-1,\left\lfloor\frac{M-X^2}{Y}\right\rfloor\right)
$$</div>

那么这一段的贡献为

<div class="math-display">$$
\sum_{W=Y+1}^{W_2}p(\lfloor X/W\rfloor)
$$</div>

----

实现中，我们对每个 `$X$` 预处理以下两个前缀和：

<div class="math-display">$$
F_p(t)=\sum_{W=1}^t\operatorname{pref}_p(X,W),\qquad Q_p(t)=\sum_{W=1}^tp(\lfloor X/W\rfloor)
$$</div>

于是还剩下这样一类求和需要处理：

<div class="math-display">$$
G_p(M,X,Y;L,R)=\sum_{W=L}^R\operatorname{pref}_p(A_W,W)
$$</div>

### `$G_p$`

用之前推导过的公式展开 `$\operatorname{pref}_p$`：

<div class="math-display">$$
\begin{aligned}
G_p(M,X,Y;L,R)
&amp;=\sum_{W=L}^R\operatorname{pref}_p(A_W,W)\\
&amp;=\sum_{W=L}^R\left((A_W+1)p(q_W)+WB_p(q_W)\right)
\end{aligned}
$$</div>

其中

<div class="math-display">$$
q_W=\left\lfloor\frac{A_W}{W}\right\rfloor=\left\lfloor\frac{M-YW}{XW}\right\rfloor=\left\lfloor\frac{M}{XW}-\frac{Y}{X}\right\rfloor
$$</div>

我们对 `$q_W$` 进行一个类似整除分块的操作。具体而言，`$q_W$` 与 `$\lfloor N/d\rfloor$` 类似，可以分为值相等的若干个段，且若该段的左端点 `$l$` 确定，该段的右端点也确定为 `$r=\lfloor M/(Xq_l+Y)\rfloor$`。

对一段确定的 `$q_W$`，该段内的和有两种算法：一是直接求和，复杂度 `$O(len)$`；二是对 `$\sum A_W$` 套类欧，复杂度 `$O(\log)$`。由于 `$q_W$` 的变化与整除分块类似，当 `$W$` 较小时每段的长度较小，可以设一个平衡阈值 `$T=c\sqrt{M/X}$`，当 `$W\le T$` 时直接计算，当 `$W>T$` 时用类欧。实现中可以取 `$c=4\sim 8$`。

每个 `$G_p$` 的计算类似于一个 `$\sqrt M$` 大小的整除分块，单次复杂度为 `$O(\sqrt{M/X}\log M)$`。计算 `$G_p$` 时可以同时计算 `$p=g,h$` 的值。

### 复杂度分析

需要预处理 `$\mu$` 和 `$\mu*\mu$` 及其前缀和，以及 `$B_p$`，复杂度 `$O(N\log N)$`。

后续计算中，显然瓶颈在 `$G_p$` 部分。对单个 `$C(M)$`，复杂度为：

<div class="math-display">$$
T_{C(M)}=O\left(\sum_{X\le\sqrt M}X\sqrt{M/X}\log M\right)=O(M^{5/4}\log M)
$$</div>

对整个 `$S$` 的计算，有

<div class="math-display">$$
T_{S(N)}=O\left(\sum_{M\in\{\lfloor N/d\rfloor\}}T_{C(M)}\right)=O(N^{5/4}\log N)
$$</div>

故总复杂度为 `$O(N^{5/4}\log N)$`。

注意常数因子对程序用时的影响，比如使用题目提示中给出的除法优化、类欧计算使用迭代而非递归等。同时注意到所有与 `$g,h$` 的值无关的求和均不可能超过 `long long` 范围（大小大致为 `$O(N^2\operatorname{polylog})$`），可以酌情减少取模次数。

```cpp
#include <utility>
#include <cstdio>
#include <vector>
#include <cmath>

using std::vector;
using ll = long long;
using pii = std::pair < int, int >;

const int MOD = 998244353;

#define toLL(x) static_cast < ll > (x)
#define mkp(x, y) std::make_pair(x, y)
#define mkpp(f) mkp(f(g), f(h))

vector < int > spf, mu, mu_S, mu2, mu2_S;
vector < ll > tri;
vector < double > inv;

inline int add(int x, int y) { x += y; return x >= MOD ? x - MOD : x; }
inline int sub(int x, int y) { return add(x, MOD - y); }
inline int mul(int x, int y) { return toLL(x) * y % MOD; }
inline int dv(int x, int d) { return static_cast < int > (x * inv[d] + 1e-9); }
inline int norm(ll x) { x %= MOD; return x < 0 ? x + MOD : x; }

template < class T > inline T min(T a, T b) { return a < b ? a : b; }
template < class T > inline T max(T a, T b) { return a > b ? a : b; }

inline pii operator + (pii x, pii y) { return mkp(add(x.first, y.first), add(x.second, y.second)); }
inline pii operator - (pii x, pii y) { return mkp(sub(x.first, y.first), sub(x.second, y.second)); }

struct Poly {
    vector < int > val, Bq;

    Poly(int _N) { val.resize(_N + 1); }

    void Init(int N) {
        Bq.resize(N + 1);

        int val_S = val[0];
        for(int x = 1; x <= N; x ++)
            Bq[x] = norm(val_S - toLL(x) * val[x]), val_S = add(val_S, val[x]);
    }

    inline int operator () (const int x) const { return val[x]; }

    inline friend int B(Poly& p, int x) { return p.Bq[x]; }

    inline friend int pref(Poly& p, int A, int d, int q) {
        return (toLL(A + 1) * p(q) + toLL(d) * B(p, q)) % MOD;
    }

    inline friend int pref(Poly& p, int A, int d) { return pref(p, A, d, dv(A, d)); }
};

void init(int N) {
    inv.resize(N + 1);
    for(int i = 1;i <= N; i ++) inv[i] = 1.0 / i;

    spf.resize(N + 1);
    for(int i = 2; i <= N; i ++)
        if(!spf[i]) for(int j = 2; j <= N / i; j ++) spf[i * j] = i;

    mu.resize(N + 1), mu[1] = 1;
    for(int i = 2; i <= N; i ++) {
        if(!spf[i]) mu[i] = -1;
        else {
            int ip = i / spf[i];
            mu[i] = (ip % spf[i]) ? -mu[ip] : 0;
        }
    }
    mu_S.resize(N + 1);
    for(int i = 1; i <= N; i ++) mu_S[i] = mu_S[i - 1] + mu[i];

    mu2.resize(N + 1);
    for(int i = 1; i <= N; i ++)
        for(int j = 1; j <= N / i; j ++)
            mu2[i * j] += mu[i] * mu[j];
    mu2_S.resize(N + 1);
    for(int i = 1; i <= N; i ++) mu2_S[i] = mu2_S[i - 1] + mu2[i];

    tri.resize(N + 1);
    for(int i = 1; i <= N; i ++) tri[i] = toLL(i) * (i + 1) / 2;
}

inline ll R(int M, Poly& g, Poly& h) {
    ll res = 0;

    for(int x = 1; (x << 1 | 1) <= M; x ++) {
        int rho = (x == 1) ? g(1) : sub(g(x - 1), g(x));
        if(!rho) continue;

        int Wm = dv(M - x, x + 1);
        for(int w = 1; w <= Wm; w ++) {
            int Zm = dv(M - w, x);
            res = (res + toLL(rho) * (pref(h, Zm, w) + MOD - h(1))) % MOD;
        }
    }

    return res;
}

inline ll f(int n, int a, int b, int c) {
    ll res = 0;

    for(;;) {
        if(a >= c) {
            int q = dv(a, c);
            res += tri[n - 1] * q, a -= q * c;
        }

        if(b >= c) {
            int q = dv(b, c);
            res += toLL(n) * q, b -= q * c;
        }

        int m = a * n + b;
        if(m < c) break;

        n = dv(m, c);
        b = m - n * c;
        std::swap(a, c);
    }

    return res;
}

inline pii G(Poly& g, Poly& h, int M, int X, int Y, int L, int R, int T) {
    pii res = mkp(0, 0);

    if(L > R) return res;

    T = min(T, R);
    for(int w = L; w <= T; w ++) {
        int Aw = dv(M - Y * w, X), q = dv(Aw, w);

        auto cop = [&](Poly& p) { return (toLL(Aw + 1) * p(q) + toLL(w) * B(p, q)) % MOD; };
        res = res + mkpp(cop);
    }

    for(int q, r, l = max(L, T + 1); l <= R; l = r + 1) {
        q = dv(M - Y * l, X * l), r = min(R, dv(M, X * q + Y));
        int len = r - l + 1;

        int c1 = norm(f(len, Y, M - Y * r, X) + len);
        int c2 = norm(toLL(l + r) * len / 2);

        auto cop = [&](Poly& p) { return (toLL(c1) * p(q) + toLL(c2) * B(p, q)) % MOD; };
        res = res + mkpp(cop);
    }

    return res;
}

inline ll C(int M, Poly& g, Poly& h) {
    ll res = 0;
    int Xm = static_cast < int > (sqrt(M));
    vector < int > Fg(Xm + 1), Fh(Xm + 1);
    vector < int > Qg(Xm + 1), Qh(Xm + 1);

    for(int x = 2; x <= Xm; x ++) {
        for(int i = 1; i <= x; i ++) {
            int xi = dv(x, i);
            Fg[i] = add(Fg[i - 1], pref(g, x, i, xi)), Fh[i] = add(Fh[i - 1], pref(h, x, i, xi));
            Qg[i] = add(Qg[i - 1], g(xi)), Qh[i] = add(Qh[i - 1], h(xi));
        }

        int T = 6 * static_cast < int > (sqrt(dv(M, x)));

        for(int y = 1; y < x; y ++) {
            pii coeff = mkp(0, 0);
            int wg = dv(x, y), R = M - x * (x + 1);

            if(R > 0) {
                int w0 = min(x, dv(R, y));
                coeff = coeff + G(g, h, M, x, y, 1, w0, T) - mkp(Fg[w0], Fh[w0]);
            }

            int w1 = dv(M - x, x + y);
            if(w1 > x) {
                coeff = coeff + G(g, h, M, x, y, x + 1, w1, T);

                int len = w1 - x;
                coeff = coeff - mkp(mul(len, g(1)), mul(len, h(1)));
            }

            int w2 = min(x - 1, dv(M - x * x, y));
            if(w2 > y) coeff = coeff + mkp(sub(Qg[w2], Qg[y]), sub(Qh[w2], Qh[y]));

            res = (res + toLL(g(wg)) * coeff.second + toLL(h(wg)) * coeff.first) % MOD;

            if(x * x + y * y <= M) res = (res + toLL(g(wg)) * h(wg)) % MOD;
        }
    }

    return res;
}

int solve(int N, Poly& g, Poly& h) {
    int res = 0;

    for(int m, r, l = 1; l <= N; l = r + 1) {
        m = dv(N, l), r = dv(N, m);

        int c1 = mu2_S[r] - mu2_S[l - 1], c2 = mu_S[r] - mu_S[l - 1];

        if(c1) res = norm(res + 2LL * c1 * C(m, g, h));
        if(c2) res = norm(res + toLL(c2) * R(m, g, h));
    }

    return res;
}

int main() {
    int N; scanf("%d", &N);
    Poly g(N), h(N);
    for(int i = 1; i <= N; i ++) scanf("%d", &g.val[i]);
    for(int i = 1; i <= N; i ++) scanf("%d", &h.val[i]);

    if(N < 3) { puts("0"); return 0; }

    g.Init(N), h.Init(N);
    init(N);

    int ans = solve(N, g, h);

    printf("%d\n", ans);

    return 0;
}
```
