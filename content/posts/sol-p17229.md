## Splitting Trick

考察 $x&#47;y$ 的连分数表示 $x&#47;y&#61;&#91;a&#95;0&#59;a&#95;1&#44;&#92;dots&#44;a&#95;k&#93;$，其为欧几里得算法中的商序列。一般而言其有两种解释：

### Continuants

数列 $b&#95;0&#44;&#92;dots&#44;b&#95;k$ 的 continuant $K&#40;b&#95;0&#44;&#92;dots&#44;b&#95;k&#41;$ 是如下递归定义的多项式：

- $K&#40;&#41; &#61; 1$（空序列）；
- $K&#40;b&#95;0&#41; &#61; b&#95;0$；
- $k&#92;ge1$ 时：$K&#40;b&#95;0&#44;&#92;dots&#44;b&#95;k&#41; &#61; b&#95;kK&#40;b&#95;0&#44; &#92;dots&#44; b&#95;&#123;k&#45;1&#125;&#41; &#43; K&#40;b&#95;0&#44; &#92;dots&#44; b&#95;&#123;k&#45;2&#125;&#41;$。

Continuants 相关的性质大多由数学归纳法易证。下列出几个较为重要的性质：

**1. 回文性质** $K&#40;b&#95;0&#44; &#92;ldots&#44; b&#95;k&#41; &#61; K&#40;b&#95;k&#44; &#92;ldots&#44; b&#95;0&#41;$。因此等价地有左递推：
$$
K&#40;b&#95;0&#44; &#92;ldots&#44; b&#95;k&#41; &#61; b&#95;0 &#92;cdot K&#40;b&#95;1&#44; &#92;ldots&#44; b&#95;k&#41; &#43; K&#40;b&#95;2&#44; &#92;ldots&#44; b&#95;k&#41;
$$

下为书写简便，对给定的连分数商序列 $&#92;&#123;a&#95;n&#92;&#125;$，记 $Q&#40;l&#44; r&#41; &#61; K&#40;a&#95;l&#44; &#92;ldots&#44; a&#95;r&#41;$（$l &#92;le r$），并约定 $Q&#40;l&#44; l&#45;1&#41; &#61; 1&#44;Q&#40;l&#44;l&#45;2&#41;&#61;0$。

**2. 与连分数的关系** 对 $x&#47;y &#61; &#91;a&#95;0&#44; a&#95;1&#44; &#92;dots&#44; a&#95;k&#93;$（$&#92;gcd&#40;x&#44; y&#41; &#61; 1$），其收敛子 $p&#94;&#42;&#95;i&#47;q&#94;&#42;&#95;i&#61;&#91;a&#95;0&#44;&#92;dots&#44;a&#95;i&#93;$ 满足
$$
p&#94;&#42;&#95;i &#61; Q&#40;0&#44; i&#41;&#44; &#92;quad q&#94;&#42;&#95;i &#61; Q&#40;1&#44; i&#41;
$$

特别地，$x &#61; Q&#40;0&#44; k&#41;$，$y &#61; Q&#40;1&#44; k&#41;$。

更泛化地说，从 $l$ 到 $r$ 的连分数序列段，由之前的回文性质，有正向和反向两种表示方法：

$$
&#92;begin&#123;gathered&#125;
&#91;a&#95;l&#44;a&#95;&#123;l&#43;1&#125;&#44;&#92;dots&#44;a&#95;r&#93;&#61;&#92;frac&#123;Q&#40;l&#44;r&#41;&#125;&#123;Q&#40;l&#43;1&#44;r&#41;&#125; &#92;&#92;
&#91;a&#95;r&#44;a&#95;&#123;r&#45;1&#125;&#44;&#92;dots&#44;a&#95;l&#93;&#61;&#92;frac&#123;Q&#40;l&#44;r&#41;&#125;&#123;Q&#40;l&#44;r&#45;1&#41;&#125;
&#92;end&#123;gathered&#125;
$$

**3. Euler 恒等式** 对 $l &#92;le m &#60; r$：
$$
Q&#40;l&#44; r&#41; &#61; Q&#40;l&#44; m&#41; &#92;cdot Q&#40;m&#43;1&#44; r&#41; &#43; Q&#40;l&#44; m&#45;1&#41; &#92;cdot Q&#40;m&#43;2&#44; r&#41;
$$

### Matrices

类似 Half-GCD 的视角，欧几里得算法可以看作一系列矩阵的连乘：
$$
&#92;begin&#123;pmatrix&#125;x&#38;&#42;&#92;&#92;y&#38;&#42;&#92;end&#123;pmatrix&#125;&#61;M&#61;&#92;prod&#95;&#123;i&#61;0&#125;&#94;kM&#40;a&#95;i&#41;&#92;quad&#92;text&#123;where &#125;M&#40;a&#41;&#61;&#92;begin&#123;pmatrix&#125;a&#38;1&#92;&#92;1&#38;0&#92;end&#123;pmatrix&#125;
$$
由于矩阵乘法有结合律，可以从中间某个地方断开，考察连续一段的乘积：
$$
P&#40;l&#44;r&#41;&#61;&#92;prod&#95;&#123;i&#61;l&#125;&#94;rM&#40;a&#95;i&#41;
$$
可以验证
$$
P&#40;l&#44;r&#41;&#61;&#92;begin&#123;pmatrix&#125;
Q&#40;l&#44;r&#41; &#38; Q&#40;l&#44; r&#45;1&#41;&#92;&#92;
Q&#40;l&#43;1&#44;r&#41; &#38; Q&#40;l&#43;1&#44;r&#45;1&#41;
&#92;end&#123;pmatrix&#125;
$$
如果考察 $P&#40;l&#44;r&#41;&#61;P&#40;l&#44;m&#41;P&#40;m&#43;1&#44;r&#41;$，可以得到 Euler 恒等式。

### Split

考虑将 $M$ 拆成若干个区间乘积 $P&#40;l&#95;i&#44;r&#95;i&#41;$ 之积，即

$$
M&#61;&#92;prod&#95;&#123;i&#61;1&#125;&#94;sP&#40;l&#95;i&#44;r&#95;i&#41;&#44;&#92;quad l&#95;1&#61;0&#44;r&#95;s&#61;k&#44;&#92;quad l&#95;i&#61;r&#95;&#123;i&#45;1&#125;&#43;1&#40;2&#92;le i&#92;le s&#41;
$$

将右侧的乘积展开，就能得到关于 $x&#44;y$ 的一些等式。一般而言，如果大量的 $P$ 是确定的，只留 $1$（平凡）或 $2$ 个自由的 $P$，这个等式的形式会易于处理。下以 $s&#61;2$ 的情况为例，这也是本题的情况：
$$
&#92;begin&#123;pmatrix&#125;x&#38;&#42;&#92;&#92;y&#38;&#42;&#92;end&#123;pmatrix&#125;&#61;&#92;begin&#123;pmatrix&#125;
Q&#40;0&#44;t&#41; &#38; Q&#40;0&#44;t&#45;1&#41;&#92;&#92;
Q&#40;1&#44;t&#41; &#38; Q&#40;1&#44;t&#45;1&#41;
&#92;end&#123;pmatrix&#125;
&#92;begin&#123;pmatrix&#125;
Q&#40;t&#43;1&#44;k&#41; &#38; Q&#40;t&#43;1&#44;k&#45;1&#41;&#92;&#92;
Q&#40;t&#43;2&#44;k&#41; &#38; Q&#40;t&#43;2&#44;k&#45;1&#41;
&#92;end&#123;pmatrix&#125;
$$

考察右侧矩阵乘法中生成左侧矩阵 $&#40;1&#44;1&#41;$ 位置（即值 $x$）的式子：
$$
x&#61;Q&#40;0&#44;t&#41;&#92;cdot Q&#40;t&#43;1&#44;k&#41;&#43;Q&#40;0&#44;t&#45;1&#41;&#92;cdot Q&#40;t&#43;2&#44;k&#41;
$$

令
$$
X&#61;Q&#40;0&#44;t&#41;&#44;&#92;quad Y&#61;Q&#40;0&#44;t&#45;1&#41;&#44;&#92;quad Z&#61;Q&#40;t&#43;1&#44;k&#41;&#44;&#92;quad W&#61;Q&#40;t&#43;2&#44;k&#41;
$$
则我们几乎建立了一个 $&#40;x&#44;y&#44;t&#41;$ 到 $&#40;X&#44;Y&#44;Z&#44;W&#41;$ 的双射（边界情况需要修正）。对 $&#40;x&#44;y&#44;t&#41;$ 的约束为
$$
1&#92;le y&#60;x&#92;le N&#44;&#92;quad 0&#92;le t&#60;k
$$
对 $&#40;X&#44;Y&#44;Z&#44;W&#41;$ 的约束为
$$
&#92;gcd&#40;X&#44;Y&#41;&#61;&#92;gcd&#40;Z&#44;W&#41;&#61;1&#44;&#92;quad X&#92;ge Y&#92;ge1&#44;&#92;&#44;Z&#92;ge W&#92;ge1&#44;&#92;quad XZ&#43;YW&#61;x&#92;le N
$$
该换元的好处是去除了极难处理的 $t$ 的约束，同时仍能表示原来的连分数序列，因为：

$$
&#92;frac XY&#61;&#91;a&#95;t&#59;a&#95;&#123;t&#45;1&#125;&#44;&#92;dots&#44;a&#95;0&#93;&#44;&#92;quad &#92;frac ZW&#61;&#91;a&#95;&#123;t&#43;1&#125;&#59;a&#95;&#123;t&#43;2&#125;&#44;&#92;dots&#44; a&#95;k&#93;
$$

因此，我们只需要把 $X&#47;Y$ 的连分数序列反向，然后和 $Z&#47;W$ 的连分数序列拼在一起，就得到 $x&#47;y$ 的连分数序列。

对 $s&#62;2$，但仍只有两个自由的 $P$ 的情况，我们实际上是枚举了连分数序列中的两个自由段，最后将它们其一反向，并与其他的非自由段拼接在一起，此处不作额外推导。

## Sol

本题解介绍一个较容易理解且常数较小的 $O&#40;N&#94;&#123;5&#47;4&#125;&#92;log N&#41;$ 算法。~~写 Sol 时的我尚不知道 std 会被 @ForgotMe 的赛时代码爆得渣都不剩，orz ForgotMe~~

约定 $g&#40;0&#41;&#61;h&#40;0&#41;&#61;0$。设连分数表示 $a&#47;b&#61;&#91;q&#95;0&#44; &#92;dots&#44; q&#95;k&#93;$，那么 $f&#40;a&#44;b&#41;&#61;&#92;sum g&#40;q&#95;i&#41;h&#40;q&#95;&#123;i&#43;1&#125;&#41;$。该求和的每一项都对应之前所述的一个 split。用取整符号可以提取出连分数的首项；再对所有互质对 $a&#44;b$ 求和，我们就大概得到这样的式子：

$$
S&#40;N&#41;&#92;sim&#92;sum&#95;&#123;&#92;substack&#123;XZ&#43;YW&#92;le N&#92;&#92;X&#92;ge Y&#44;&#92;&#44; Z&#92;ge W&#92;&#92; &#92;gcd&#40;X&#44;Y&#41;&#61;&#92;gcd&#40;Z&#44;W&#41;&#61;1&#125;&#125;g&#40;&#92;lfloor X&#47;Y&#92;rfloor&#41;h&#40;&#92;lfloor Z&#47;W&#92;rfloor&#41;
$$

当然我们还要处理边界情况，下进行分析。

1. 对 $Z&#61;W$ 的情况，连分数末尾项必为 $1$，但欧几里得算法的最后一步商必不可能为 $1$，直接排除；
2. 对 $Y&#92;neq 1$，$X&#47;Y$ 对应两个连分数（因为 $&#91;&#92;dots&#44; t&#93;&#61;&#91;&#92;dots&#44; t&#45;1&#44; 1&#93;$，$Y&#92;neq 1$ 保证了 $&#92;dots$ 不为空），答案中贡献为 $2g&#40;&#92;lfloor X&#47;Y&#92;rfloor&#41;h&#40;&#92;lfloor Z&#47;W&#92;rfloor&#41;$；
3. 对 $Y&#61;1&#44;&#92;&#44; X&#92;ge 2$，$X&#47;Y&#61;&#91;X&#93;&#61;&#91;X&#45;1&#59; 1&#93;$，答案中贡献为 $&#40;g&#40;X&#41;&#43;g&#40;X&#45;1&#41;&#41;h&#40;&#92;lfloor Z&#47;W&#92;rfloor&#41;$；
4. 对 $X&#61;Y&#61;1$，答案中贡献为 $g&#40;1&#41;h&#40;&#92;lfloor Z&#47;W&#92;rfloor&#41;$。

统计答案时，我们分为 $X&#62;Y&#44;&#92;&#44; Z&#62;W$ 的主体部分和剩下的修正项。具体地，定义修正系数：

$$
&#92;rho&#40;x&#41;&#61;&#92;begin&#123;cases&#125;g&#40;1&#41;&#38;x&#61;1&#92;&#92;g&#40;x&#45;1&#41;&#45;g&#40;x&#41;&#38;x&#92;ge 2&#92;end&#123;cases&#125;
$$

那么 $S&#40;N&#41;$ 可以拆成（主体求和记作 $C&#95;0$，修正项记作 $R&#95;0$）：

$$
S&#40;N&#41;&#61;2&#92;underbrace&#123;&#92;sum&#95;&#123;&#92;substack&#123;XZ&#43;YW&#92;le N&#92;&#92;X&#62;Y&#92;ge 1&#44;&#92;&#44; Z&#62;W&#92;ge 1&#92;&#92; &#92;gcd&#40;X&#44;Y&#41;&#61;&#92;gcd&#40;Z&#44;W&#41;&#61;1&#125;&#125;g&#40;&#92;lfloor X&#47;Y&#92;rfloor&#41;h&#40;&#92;lfloor Z&#47;W
&#92;rfloor&#41;&#125;&#95;&#123;C&#95;0&#40;N&#41;&#125;&#43;&#92;underbrace&#123;&#92;sum&#95;&#123;&#92;substack&#123;XZ&#43;W&#92;le N&#92;&#92;X&#92;ge 1&#44;&#92;&#44; Z&#62;W&#92;ge 1&#92;&#92;&#92;gcd&#40;Z&#44;W&#41;&#61;1&#125;&#125;&#92;rho&#40;X&#41;h&#40;&#92;lfloor Z&#47;W&#92;rfloor&#41;&#125;&#95;&#123;R&#95;0&#40;N&#41;&#125;
$$

莫反之后即需要处理去掉互质条件的两项求和，即：

$$
&#92;begin&#123;aligned&#125;
C&#95;0&#40;N&#41;&#61;&#92;sum&#95;&#123;d&#92;ge 1&#125;&#40;&#92;mu&#42;&#92;mu&#41;&#40;d&#41;C&#40;&#92;lfloor N&#47;d&#92;rfloor&#41;&#44;&#38;&#92;quad&#92;text&#123;where &#125; C&#40;M&#41;&#61;&#92;sum&#95;&#123;&#92;substack&#123;XZ&#43;YW&#92;le M&#92;&#92;X&#62;Y&#92;ge 1&#44;&#92;&#44; Z&#62;W&#92;ge 1&#125;&#125;g&#40;&#92;lfloor X&#47;Y&#92;rfloor&#41;h&#40;&#92;lfloor Z&#47;W&#92;rfloor&#41;&#92;&#92;
R&#95;0&#40;N&#41;&#61;&#92;sum&#95;&#123;d&#92;ge 1&#125;&#92;mu&#40;d&#41;R&#40;&#92;lfloor N&#47;d&#92;rfloor&#41;&#44;&#38;&#92;quad&#92;text&#123;where &#125; R&#40;M&#41;&#61;&#92;sum&#95;&#123;&#92;substack&#123;XZ&#43;W&#92;le M&#92;&#92;X&#92;ge 1&#44;&#92;&#44; Z&#62;W&#92;ge 1&#125;&#125;&#92;rho&#40;X&#41;h&#40;&#92;lfloor Z&#47;W&#92;rfloor&#41;
&#92;end&#123;aligned&#125;
$$

接下来讨论 $C&#40;M&#41;$ 和 $R&#40;M&#41;$。

### $&#92;operatorname&#123;pref&#125;$

对 $p&#92;in&#92;&#123;g&#44; h&#92;&#125;$，以下会常用到这样一类前缀和：

$$
&#92;operatorname&#123;pref&#125;&#95;p&#40;A&#44;d&#41;&#61;&#92;sum&#95;&#123;x&#61;1&#125;&#94;Ap&#40;&#92;lfloor x&#47;d&#92;rfloor&#41;
$$

令 $q&#61;&#92;lfloor A&#47;d&#92;rfloor$，那么 $&#92;lfloor x&#47;d&#92;rfloor$ 跨越了 $q&#45;1$ 个完整的“块”，以及一个 $&#40;A&#92;bmod d&#41;&#43;1$ 大小的余项。因此得到：

$$
&#92;operatorname&#123;pref&#125;&#95;p&#40;A&#44;d&#41;&#61;d&#92;sum&#95;&#123;t&#61;1&#125;&#94;&#123;q&#45;1&#125;p&#40;t&#41;&#43;&#40;A&#45;dq&#43;1&#41;p&#40;&#92;lfloor A&#47;d&#92;rfloor&#41;
$$

另有 $&#92;operatorname&#123;pref&#125;&#95;p&#40;x&#44;x&#41;&#61;p&#40;1&#41;&#44;&#92;&#44; &#92;operatorname&#123;pref&#125;&#95;p&#40;A&#44;d&#41;&#61;0&#40;A&#60;d&#41;$。

实现中，我们预处理

$$
B&#95;p&#40;q&#41;&#61;&#92;sum&#95;&#123;t&#61;1&#125;&#94;&#123;q&#45;1&#125;p&#40;t&#41;&#45;qp&#40;q&#41;&#44;&#92;quad q&#92;ge 1
$$

那么可以 $&#92;operatorname&#123;pref&#125;&#95;p&#40;A&#44;d&#41;&#61;&#40;A&#43;1&#41;p&#40;q&#41;&#43;dB&#95;p&#40;q&#41;$，$O&#40;1&#41;$ 计算。

### $R$

枚举 $X&#44;W$，此时 $Z&#92;le&#92;lfloor&#40;M&#45;W&#41;&#47;X&#92;rfloor$。故固定 $X&#44;W$ 时的贡献为

$$
&#92;operatorname&#123;pref&#125;&#95;h&#92;left&#40;&#92;left&#92;lfloor&#92;frac&#123;M&#45;W&#125;&#123;X&#125;&#92;right&#92;rfloor&#44;W&#92;right&#41;&#45;&#92;operatorname&#123;pref&#125;&#95;h&#40;W&#44;W&#41;
$$

由于 $Z&#92;ge 2$，对 $X$ 有 $2X&#43;1&#92;le M$。由于 $Z&#92;ge W&#43;1$，对 $W$ 有 $X&#40;W&#43;1&#41;&#43;W&#92;le M$，即 $W&#92;le&#92;lfloor&#40;M&#45;X&#41;&#47;&#40;X&#43;1&#41;&#92;rfloor$。故对 $R&#40;M&#41;$：

$$
R&#40;M&#41;&#61;&#92;sum&#95;&#123;&#92;substack&#123;X&#92;ge 1&#92;&#92;2X&#43;1&#92;le M&#125;&#125;&#92;rho&#40;X&#41;&#92;sum&#95;&#123;W&#61;1&#125;&#94;&#123;&#92;left&#92;lfloor&#92;frac&#123;M&#45;X&#125;&#123;X&#43;1&#125;&#92;right&#92;rfloor&#125;&#92;left&#40;&#92;operatorname&#123;pref&#125;&#95;h&#92;left&#40;&#92;left&#92;lfloor&#92;frac&#123;M&#45;W&#125;&#123;X&#125;&#92;right&#92;rfloor&#44;W&#92;right&#41;&#45;&#92;operatorname&#123;pref&#125;&#95;h&#40;W&#44;W&#41;&#92;right&#41;
$$

直接枚举 $&#40;X&#44;W&#41;$，单次计算复杂度为 $O&#40;&#92;sum&#95;&#123;X&#60;M&#47;2&#125;M&#47;X&#41;&#61;O&#40;M&#92;log M&#41;$。

### $C$

注意到求和限制中 $&#40;X&#44; Y&#41;$ 和 $&#40;Z&#44; W&#41;$ 的地位是完全对称的，考虑限定其字典序顺序。分为两种情况：$&#40;X&#44;Y&#41;&#61;&#40;Z&#44;W&#41;$ 和 $&#40;X&#44;Y&#41;&#60;&#95;&#92;text&#123;lex&#125;&#40;Z&#44;W&#41;$。于是有

$$
&#92;begin&#123;aligned&#125;
C&#40;M&#41;
&#38;&#61;&#92;sum&#95;&#123;&#40;X&#44;Y&#41;&#61;&#40;Z&#44;W&#41;&#125;g&#40;&#92;lfloor X&#47;Y&#92;rfloor&#41;h&#40;&#92;lfloor Z&#47;W&#92;rfloor&#41;&#92;&#92;
&#38;&#43;&#92;sum&#95;&#123;&#40;X&#44;Y&#41;&#60;&#95;&#92;text&#123;lex&#125;&#40;Z&#44;W&#41;&#125;&#92;left&#40;g&#40;&#92;lfloor X&#47;Y&#92;rfloor&#41;h&#40;&#92;lfloor Z&#47;W&#92;rfloor&#41;&#43;h&#40;&#92;lfloor X&#47;Y&#92;rfloor&#41;g&#40;&#92;lfloor Z&#47;W&#92;rfloor&#41;&#92;right&#41;
&#92;end&#123;aligned&#125;
$$

由于 $X&#92;le Z$，有 $X&#92;le &#92;sqrt&#123;XZ&#125;&#92;le &#92;sqrt M$，这大幅减小了求和范围。

$&#40;X&#44;Y&#41;&#61;&#40;Z&#44;W&#41;$ 的情况是简单的：直接枚举 $&#40;X&#44;Y&#41;$ 即可，复杂度 $O&#40;M&#41;$。这一步可以在后一种情况的循环中顺手加上。

对 $&#40;X&#44;Y&#41;&#60;&#95;&#92;text&#123;lex&#125;&#40;Z&#44;W&#41;$ 的情况，考虑枚举 $&#40;X&#44;Y&#41;$。固定 $&#40;X&#44;Y&#44;W&#41;$ 后，有 $Z&#92;le&#92;lfloor&#40;M&#45;YW&#41;&#47;X&#92;rfloor$。设 $Z$ 的上限 $A&#95;W&#61;&#92;lfloor&#40;M&#45;YW&#41;&#47;X&#92;rfloor$，则我们要求的是：

$$
&#92;sum&#95;&#123;&#92;substack&#123;W&#92;ge 1&#92;&#92; A&#95;W&#92;ge&#92;max&#40;X&#44;W&#41;&#125;&#125;&#92;sum&#95;&#123;&#92;max&#40;X&#44;W&#41;&#92;le Z&#92;le A&#95;W&#125;p&#40;&#92;lfloor Z&#47;W&#92;rfloor&#41;
$$

注意限定字典序后 $p$ 也可能取 $g$。这里的边界不等式需要稍精细的处理，我们更细地分成三种大小关系来讨论：

1. $Z&#62;X&#92;ge W$

一定有 $Z&#62;W$，故只需保证 $Z&#62;X$ 存在，即有 $X&#40;X&#43;1&#41;&#43;YW&#92;le M$。令

$$
W&#95;0&#61;&#92;min&#92;left&#40;X&#44;&#92;left&#92;lfloor&#92;frac&#123;M&#45;X&#40;X&#43;1&#41;&#125;&#123;Y&#125;&#92;right&#92;rfloor&#92;right&#41;
$$

那么这一段的贡献为

$$
&#92;sum&#95;&#123;W&#61;1&#125;&#94;&#123;W&#95;0&#125;&#92;left&#40;&#92;operatorname&#123;pref&#125;&#95;p&#40;A&#95;W&#44;W&#41;&#45;&#92;operatorname&#123;pref&#125;&#95;p&#40;X&#44;W&#41;&#92;right&#41;
$$

2. $Z&#62;X&#44; W&#62;X$

此时 $Z&#62;W$ 更强，即需保证 $X&#40;W&#43;1&#41;&#43;YW&#92;le M$。令

$$
W&#95;1&#61;&#92;left&#92;lfloor&#92;frac&#123;M&#45;X&#125;&#123;X&#43;Y&#125;&#92;right&#92;rfloor
$$

那么这一段的贡献为

$$
&#92;sum&#95;&#123;W&#61;X&#43;1&#125;&#94;&#123;W&#95;1&#125;&#92;left&#40;&#92;operatorname&#123;pref&#125;&#95;p&#40;A&#95;W&#44;W&#41;&#45;&#92;operatorname&#123;pref&#125;&#95;p&#40;W&#44;W&#41;&#92;right&#41;
$$

3. $X&#61;Z$

$W$ 的限制为 $Y&#60;W&#60;X$，且 $X&#94;2&#43;YW&#92;le M$。令

$$
W&#95;2&#61;&#92;min&#92;left&#40;X&#45;1&#44;&#92;left&#92;lfloor&#92;frac&#123;M&#45;X&#94;2&#125;&#123;Y&#125;&#92;right&#92;rfloor&#92;right&#41;
$$

那么这一段的贡献为

$$
&#92;sum&#95;&#123;W&#61;Y&#43;1&#125;&#94;&#123;W&#95;2&#125;p&#40;&#92;lfloor X&#47;W&#92;rfloor&#41;
$$

实现中，我们对每个 $X$ 预处理以下两个前缀和：

$$
F&#95;p&#40;t&#41;&#61;&#92;sum&#95;&#123;W&#61;1&#125;&#94;t&#92;operatorname&#123;pref&#125;&#95;p&#40;X&#44;W&#41;&#44;&#92;qquad Q&#95;p&#40;t&#41;&#61;&#92;sum&#95;&#123;W&#61;1&#125;&#94;tp&#40;&#92;lfloor X&#47;W&#92;rfloor&#41;
$$

于是还剩下这样一类求和需要处理：

$$
G&#95;p&#40;M&#44;X&#44;Y&#59;L&#44;R&#41;&#61;&#92;sum&#95;&#123;W&#61;L&#125;&#94;R&#92;operatorname&#123;pref&#125;&#95;p&#40;A&#95;W&#44;W&#41;
$$

### $G&#95;p$

用之前推导过的公式展开 $&#92;operatorname&#123;pref&#125;&#95;p$：

$$
&#92;begin&#123;aligned&#125;
G&#95;p&#40;M&#44;X&#44;Y&#59;L&#44;R&#41;
&#38;&#61;&#92;sum&#95;&#123;W&#61;L&#125;&#94;R&#92;operatorname&#123;pref&#125;&#95;p&#40;A&#95;W&#44;W&#41;&#92;&#92;
&#38;&#61;&#92;sum&#95;&#123;W&#61;L&#125;&#94;R&#92;left&#40;&#40;A&#95;W&#43;1&#41;p&#40;q&#95;W&#41;&#43;WB&#95;p&#40;q&#95;W&#41;&#92;right&#41;
&#92;end&#123;aligned&#125;
$$

其中

$$
q&#95;W&#61;&#92;left&#92;lfloor&#92;frac&#123;A&#95;W&#125;&#123;W&#125;&#92;right&#92;rfloor&#61;&#92;left&#92;lfloor&#92;frac&#123;M&#45;YW&#125;&#123;XW&#125;&#92;right&#92;rfloor&#61;&#92;left&#92;lfloor&#92;frac&#123;M&#125;&#123;XW&#125;&#45;&#92;frac&#123;Y&#125;&#123;X&#125;&#92;right&#92;rfloor
$$

我们对 $q&#95;W$ 进行一个类似整除分块的操作。具体而言，$q&#95;W$ 与 $&#92;lfloor N&#47;d&#92;rfloor$ 类似，可以分为值相等的若干个段，且若该段的左端点 $l$ 确定，该段的右端点也确定为 $r&#61;&#92;lfloor M&#47;&#40;Xq&#95;l&#43;Y&#41;&#92;rfloor$。

对一段确定的 $q&#95;W$，该段内的和有两种算法：一是直接求和，复杂度 $O&#40;len&#41;$；二是对 $&#92;sum A&#95;W$ 套类欧，复杂度 $O&#40;&#92;log&#41;$。由于 $q&#95;W$ 的变化与整除分块类似，当 $W$ 较小时每段的长度较小，可以设一个平衡阈值 $T&#61;c&#92;sqrt&#123;M&#47;X&#125;$，当 $W&#92;le T$ 时直接计算，当 $W&#62;T$ 时用类欧。实现中可以取 $c&#61;4&#92;sim 8$。

每个 $G&#95;p$ 的计算类似于一个 $&#92;sqrt M$ 大小的整除分块，单次复杂度为 $O&#40;&#92;sqrt&#123;M&#47;X&#125;&#92;log M&#41;$。计算 $G&#95;p$ 时可以同时计算 $p&#61;g&#44;h$ 的值。

### 复杂度分析

需要预处理 $&#92;mu$ 和 $&#92;mu&#42;&#92;mu$ 及其前缀和，以及 $B&#95;p$，复杂度 $O&#40;N&#92;log N&#41;$。

后续计算中，显然瓶颈在 $G&#95;p$ 部分。对单个 $C&#40;M&#41;$，复杂度为：

$$
T&#95;&#123;C&#40;M&#41;&#125;&#61;O&#92;left&#40;&#92;sum&#95;&#123;X&#92;le&#92;sqrt M&#125;X&#92;sqrt&#123;M&#47;X&#125;&#92;log M&#92;right&#41;&#61;O&#40;M&#94;&#123;5&#47;4&#125;&#92;log M&#41;
$$

对整个 $S$ 的计算，有

$$
T&#95;&#123;S&#40;N&#41;&#125;&#61;O&#92;left&#40;&#92;sum&#95;&#123;M&#92;in&#92;&#123;&#92;lfloor N&#47;d&#92;rfloor&#92;&#125;&#125;T&#95;&#123;C&#40;M&#41;&#125;&#92;right&#41;&#61;O&#40;N&#94;&#123;5&#47;4&#125;&#92;log N&#41;
$$

故总复杂度为 $O&#40;N&#94;&#123;5&#47;4&#125;&#92;log N&#41;$。

注意常数因子对程序用时的影响，比如使用题目提示中给出的除法优化、类欧计算使用迭代而非递归等。同时注意到所有与 $g&#44;h$ 的值无关的求和均不可能超过 `long long` 范围（大小大致为 $O&#40;N&#94;2&#92;operatorname&#123;polylog&#125;&#41;$），可以酌情减少取模次数。

```cpp
#include <utility>
#include <cstdio>
#include <vector>
#include <cmath>

using std::vector;
using ll = long long;
using pii = std::pair < int, int >;

const int MOD = 998244353;

#define toLL(x) static_cast < ll > (x)
#define mkp(x, y) std::make_pair(x, y)
#define mkpp(f) mkp(f(g), f(h))

vector < int > spf, mu, mu_S, mu2, mu2_S;
vector < ll > tri;
vector < double > inv;

inline int add(int x, int y) { x += y; return x >= MOD ? x - MOD : x; }
inline int sub(int x, int y) { return add(x, MOD - y); }
inline int mul(int x, int y) { return toLL(x) * y % MOD; }
inline int dv(int x, int d) { return static_cast < int > (x * inv[d] + 1e-9); }
inline int norm(ll x) { x %= MOD; return x < 0 ? x + MOD : x; }

template < class T > inline T min(T a, T b) { return a < b ? a : b; }
template < class T > inline T max(T a, T b) { return a > b ? a : b; }

inline pii operator + (pii x, pii y) { return mkp(add(x.first, y.first), add(x.second, y.second)); }
inline pii operator - (pii x, pii y) { return mkp(sub(x.first, y.first), sub(x.second, y.second)); }

struct Poly {
    vector < int > val, Bq;

    Poly(int _N) { val.resize(_N + 1); }

    void Init(int N) {
        Bq.resize(N + 1);

        int val_S = val[0];
        for(int x = 1; x <= N; x ++)
            Bq[x] = norm(val_S - toLL(x) * val[x]), val_S = add(val_S, val[x]);
    }

    inline int operator () (const int x) const { return val[x]; }

    inline friend int B(Poly& p, int x) { return p.Bq[x]; }

    inline friend int pref(Poly& p, int A, int d, int q) {
        return (toLL(A + 1) * p(q) + toLL(d) * B(p, q)) % MOD;
    }

    inline friend int pref(Poly& p, int A, int d) { return pref(p, A, d, dv(A, d)); }
};

void init(int N) {
    inv.resize(N + 1);
    for(int i = 1;i <= N; i ++) inv[i] = 1.0 / i;

    spf.resize(N + 1);
    for(int i = 2; i <= N; i ++)
        if(!spf[i]) for(int j = 2; j <= N / i; j ++) spf[i * j] = i;

    mu.resize(N + 1), mu[1] = 1;
    for(int i = 2; i <= N; i ++) {
        if(!spf[i]) mu[i] = -1;
        else {
            int ip = i / spf[i];
            mu[i] = (ip % spf[i]) ? -mu[ip] : 0;
        }
    }
    mu_S.resize(N + 1);
    for(int i = 1; i <= N; i ++) mu_S[i] = mu_S[i - 1] + mu[i];

    mu2.resize(N + 1);
    for(int i = 1; i <= N; i ++)
        for(int j = 1; j <= N / i; j ++)
            mu2[i * j] += mu[i] * mu[j];
    mu2_S.resize(N + 1);
    for(int i = 1; i <= N; i ++) mu2_S[i] = mu2_S[i - 1] + mu2[i];

    tri.resize(N + 1);
    for(int i = 1; i <= N; i ++) tri[i] = toLL(i) * (i + 1) / 2;
}

inline ll R(int M, Poly& g, Poly& h) {
    ll res = 0;

    for(int x = 1; (x << 1 | 1) <= M; x ++) {
        int rho = (x == 1) ? g(1) : sub(g(x - 1), g(x));
        if(!rho) continue;

        int Wm = dv(M - x, x + 1);
        for(int w = 1; w <= Wm; w ++) {
            int Zm = dv(M - w, x);
            res = (res + toLL(rho) * (pref(h, Zm, w) + MOD - h(1))) % MOD;
        }
    }

    return res;
}

inline ll f(int n, int a, int b, int c) {
    ll res = 0;

    for(;;) {
        if(a >= c) {
            int q = dv(a, c);
            res += tri[n - 1] * q, a -= q * c;
        }

        if(b >= c) {
            int q = dv(b, c);
            res += toLL(n) * q, b -= q * c;
        }

        int m = a * n + b;
        if(m < c) break;

        n = dv(m, c);
        b = m - n * c;
        std::swap(a, c);
    }

    return res;
}

inline pii G(Poly& g, Poly& h, int M, int X, int Y, int L, int R, int T) {
    pii res = mkp(0, 0);

    if(L > R) return res;

    T = min(T, R);
    for(int w = L; w <= T; w ++) {
        int Aw = dv(M - Y * w, X), q = dv(Aw, w);

        auto cop = [&](Poly& p) { return (toLL(Aw + 1) * p(q) + toLL(w) * B(p, q)) % MOD; };
        res = res + mkpp(cop);
    }

    for(int q, r, l = max(L, T + 1); l <= R; l = r + 1) {
        q = dv(M - Y * l, X * l), r = min(R, dv(M, X * q + Y));
        int len = r - l + 1;

        int c1 = norm(f(len, Y, M - Y * r, X) + len);
        int c2 = norm(toLL(l + r) * len / 2);

        auto cop = [&](Poly& p) { return (toLL(c1) * p(q) + toLL(c2) * B(p, q)) % MOD; };
        res = res + mkpp(cop);
    }

    return res;
}

inline ll C(int M, Poly& g, Poly& h) {
    ll res = 0;
    int Xm = static_cast < int > (sqrt(M));
    vector < int > Fg(Xm + 1), Fh(Xm + 1);
    vector < int > Qg(Xm + 1), Qh(Xm + 1);

    for(int x = 2; x <= Xm; x ++) {
        for(int i = 1; i <= x; i ++) {
            int xi = dv(x, i);
            Fg[i] = add(Fg[i - 1], pref(g, x, i, xi)), Fh[i] = add(Fh[i - 1], pref(h, x, i, xi));
            Qg[i] = add(Qg[i - 1], g(xi)), Qh[i] = add(Qh[i - 1], h(xi));
        }

        int T = 6 * static_cast < int > (sqrt(dv(M, x)));

        for(int y = 1; y < x; y ++) {
            pii coeff = mkp(0, 0);
            int wg = dv(x, y), R = M - x * (x + 1);

            if(R > 0) {
                int w0 = min(x, dv(R, y));
                coeff = coeff + G(g, h, M, x, y, 1, w0, T) - mkp(Fg[w0], Fh[w0]);
            }

            int w1 = dv(M - x, x + y);
            if(w1 > x) {
                coeff = coeff + G(g, h, M, x, y, x + 1, w1, T);

                int len = w1 - x;
                coeff = coeff - mkp(mul(len, g(1)), mul(len, h(1)));
            }

            int w2 = min(x - 1, dv(M - x * x, y));
            if(w2 > y) coeff = coeff + mkp(sub(Qg[w2], Qg[y]), sub(Qh[w2], Qh[y]));

            res = (res + toLL(g(wg)) * coeff.second + toLL(h(wg)) * coeff.first) % MOD;

            if(x * x + y * y <= M) res = (res + toLL(g(wg)) * h(wg)) % MOD;
        }
    }

    return res;
}

int solve(int N, Poly& g, Poly& h) {
    int res = 0;

    for(int m, r, l = 1; l <= N; l = r + 1) {
        m = dv(N, l), r = dv(N, m);

        int c1 = mu2_S[r] - mu2_S[l - 1], c2 = mu_S[r] - mu_S[l - 1];

        if(c1) res = norm(res + 2LL * c1 * C(m, g, h));
        if(c2) res = norm(res + toLL(c2) * R(m, g, h));
    }

    return res;
}

int main() {
    int N; scanf("%d", &N);
    Poly g(N), h(N);
    for(int i = 1; i <= N; i ++) scanf("%d", &g.val[i]);
    for(int i = 1; i <= N; i ++) scanf("%d", &h.val[i]);

    if(N < 3) { puts("0"); return 0; }

    g.Init(N), h.Init(N);
    init(N);

    int ans = solve(N, g, h);

    printf("%d\n", ans);

    return 0;
}
```
